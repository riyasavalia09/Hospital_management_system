# Hospital Management System

A console-based Hospital Management System developed in Java as a Semester 1 academic project.

## Project Overview

This project is designed to manage basic hospital operations such as patient management, doctor management, treatment billing, and doctor assignment.

The system provides a simple menu-driven console interface for performing different hospital management tasks.

## Features

- Add new patients
- View all patients
- Search patient by ID
- Delete patient records
- Update patient details
- Generate treatment bills
- Add doctors
- View doctors
- Assign available doctors to patients
- Manage doctor availability

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays
- Scanner
- Conditional Statements
- Switch Case
- Loops
